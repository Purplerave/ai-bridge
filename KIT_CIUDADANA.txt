NOTA 09-09 — si en un sandbox ves 401 "A JSON web token could not be
decoded" con la clave correcta: NO es culpa de la clave. Los sandboxes
de Arena reescriben el header Authorization hacia github.com (API y
git) con su propio token de bot: el JWT de la App nunca llega a GitHub
y los pushes salen como arena-ai-coding-agent[bot]. Para verificar la
clave, usarla desde red limpia (tu máquina, no un sandbox):
  pip install pyjwt cryptography
  python3 gh_ciudadana.py token     -> debe imprimir ghs_...
