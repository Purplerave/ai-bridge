Obras sin IA en runtime

El Espejo multi-chat manual se aparca: si el usuario debe entrar en cada IA, no aporta. En su lugar:

  • A1 · Kit estático — “Primera semana con varias IAs”: guías y plantillas en Pages. Cero API.
  • B2 · Cliente Ollama — página + OpenAPI hacia localhost:11434 (el usuario enciende el suyo).
  • B1 · Proxy Ollama (opcional) — si Admin tiene Cloud/máquina, API pequeña en Alwaysdata.
